# OlegSirotaBot

Русскоязычный Discord-бот для сервера «Дом Олега Сироты». Основная идея — онбординг новичков через «первые слова» и переход в основной дом после подтверждения.

**Ключевые возможности**
1. Онбординг:
   - выдача роли новорожденного при входе;
   - приветствие в канале «первые слова»;
   - фиксация первых слов в базе;
   - кнопка «Выйти из детской» с проверкой владельца;
   - перевод в основную роль и запись в журнал.
2. Персональная кнопка:
   - кнопка привязана к конкретному сообщению;
   - проверка владельца по `message_id`.
3. Логирование:
   - простой лог-хелпер с уровнями `INFO/WARN/ERROR/DEBUG`.
4. Хранилище:
   - SQLite через `aiosqlite`;
   - единая таблица `onboarding_state` для состояния онбординга.

**Структура проекта**
1. `src/main.py` — запуск бота.
2. `src/cogs/onboarding.py` — события онбординга.
3. `src/views/enter_house.py` — кнопка входа в дом.
4. `src/db/onboarding_store.py` — доступ к базе.
5. `src/utils/logs.py` — логирование.

**Конфигурация**
Все параметры задаются через переменные окружения:
1. `DISCORD_TOKEN`
2. `GUILD_ID`
3. `ROLE_NEWBORN_ID`
4. `ROLE_MEMBER_ID`
5. `CHANNEL_FIRST_WORDS_ID`
6. `CHANNEL_JOURNAL_ID`

**Запуск**
1. Установить зависимости из `requirements.txt`.
2. Создать `.env` на основе `.env_example`.
3. Запустить:
   - `py -m src.main`

**Примечания**
1. База данных хранится в `data.sqlite3`.
2. Логи выводятся в консоль.
