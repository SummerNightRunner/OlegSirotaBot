# Project October Roadmap

## Текущее направление

Project October развивает русскоязычного Discord-бота OlegSirotaBot для сервера "Дом Олега Сироты". Текущий фокус - стабильный онбординг новичков, базовая автоматическая модерация и безопасная эксплуатация через понятную конфигурацию и проектную документацию.

## Ближайшие этапы

1. Стабилизировать уже добавленную функциональность v2: онбординг, persistent flow, anti-spam automod и структурное логирование.
2. Закрыть эксплуатационные риски: согласовать переменные окружения, формат `.env_example`, правила хранения локальных данных и минимальный smoke-test перед запуском.
3. Описать ручной регламент проверки Discord-сценариев: вход пользователя, первые слова, кнопка выхода из детской, выдача ролей, запись в журнал.
4. Подготовить безопасный цикл релизов: backlog, daily-планы, журнал решений и проверка git hygiene перед push.

## Не в фокусе сейчас

- Расширение пользовательских команд без стабилизации онбординга и automod.
- Изменение source-кода в рамках ежедневного планирования.
- Публикация секретов, локальных баз, embeddings, model artifacts или private data.
